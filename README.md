# PySide6 Learning & Projects
This repository is dedicated to my personal **PySide6 (Qt for Python)** GUI practice and real-world projects.

## 🛠️ Tech Stack
* **Language:** Python 3.10+
* **UI Framework:** PySide6 (Qt 6)
* **Tools:** Qt Designer, Visual Studio Code
* **Environment:** Anaconda

## 🚀 Quick Start
1. **Clone the Repository**
```bash
git clone https://github.com/H2Log1/PySide6_learning.git
cd PySide6_learning

```
2. **Install Dependencies**
```bash
pip install -r requirements.txt
```
