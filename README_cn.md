本仓库用于存放一些个人 **PySide6 (Qt for Python)** GUI 实战项目。

## 🛠️ 技术栈
* **语言:** Python 3.10+
* **UI 框架:** PySide6 (Qt 6)
* **工具:** Qt Designer, Visual Studio Code
* **环境管理:** Anaconda

## 🚀 快速开始
1. **克隆仓库**
```bash
git clone https://github.com/H2Log1/PySide6_learning.git
cd PySide6_learning
```
2. **安装依赖**
```bash
pip install -r requirements.txt
```
